Este projeto tem como finalidade ajudar o usuário a entender e gerenciar seus gastos mensais e anuais, para que possa ser feito um controle de quanto está sendo cobrado.
Vem como uma abordagem visando facilitar a vida pessoal de quem está administrando seus custos, vem de uma proposta real e pessoal.
